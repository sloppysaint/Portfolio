# 🚀 My Portfolio

A modern, responsive personal portfolio website built with **Next.js**.  
Showcasing my projects and skills as an aspiring software developer.

---

## ✨ Features

- ⚡ **Blazing fast performance** with Next.js  
- 🎨 **Modern, minimal, and fully responsive design**  
- 🖼️ **Project showcase section** with images & live links  
- 📄 **Resume/CV downloadable**  
- 📱 **Mobile-friendly**  
- 📨 **Contact form**  

---

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) (for animations)
- [Vercel](https://vercel.com/) for deployment

---

## 🚧 Installation & Setup

1. **Clone the repo:**
   ```bash
   git clone https://github.com/sloppysaint/Portfolio
   cd next-first

2. **Install Dependencies:**
   ```bash
   npm install

3. **Run Locally:**
   npm run dev

4. Open http://localhost:3000 to see your portfolio.
